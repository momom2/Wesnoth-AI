# Arm W — signal rebalancing (spec, 2026-09-01; NOT launched)

Status: proposal awaiting user ruling. No box, no config committed.

## Motivation (verified, signal-profiler round 4)

At every checkpoint on the V3 arc — seed included — the applied
update is ~99% value gradient (value_inbatch norm 12x
policy_distill; proj_frac .989–.996 vs .004–.009), and the distill
targets are nearly identical to the prior (KL median 0.0025–0.0062
over ~350 legal actions). A +320-Elo teacher signal cannot transfer
through a ~1%-share channel carrying near-zero-amplitude targets —
while the component that drifts off-distribution and sabotages
search (the value head) receives essentially all the gradient.

Full numbers: docs/archive/teacher_arms_findings_20260829.md §Round 4.

## Design: two independent levers, one at a time

W1 — shrink the value channel: `value_coef` 0.5 → 0.1 (trainer.py
TrainerConfig). Direct attack on the 99% share; also the cheapest
test of the off-distribution-drift hypothesis (less value gradient
= slower drift). Risk: value head under-trains and search quality
degrades from the other side; the value tripwire (3-redraw rule)
and value_auc telemetry guard that.

W2 — strengthen the targets: `--turn-target-beta` 5 → 15 (with the
linear link — the exp link stays off, leg-3 R2 ratchet). Triples
the mass moved per accepted delta; the probe's median accepted
delta (2 atoms) then gains ~+120% before renorm instead of +40%.
Risk: amplifying grader noise; the K-tripwire and decisive-rate
guards stand.

Baseline config: arm T's recipe (TCS teacher, mover frame,
project reval, lam 1.0, policy anchor). NO value-memory step
(round 4: it was a second value channel on an already
value-dominated update; both V arms collapsed).

## Measurement

- Profiler before/after: profile the seed and each ~30k-step pin
  (8 games, seed 31337) — the target is policy proj_frac and
  target-KL moving materially, with linres ~0 as the validity
  check. Staging rule: arch-peek every checkpoint on the box that
  runs (the rounds-1-3 lesson; the FileNotFoundError guard
  enforces it).
- Strength: 24-game pin-vs-seed probes at ~27k-step spacing, as
  in the teacher arms. GAMES are the verdict, per standing ruling.
- Tripwires: K-median 10, decisive-rate, value 3-redraw, CPU
  watchdog — unchanged from leg 5.

## Cost

all-in (GPU + container storage; --disk 10), ~24h to the first
two probe points. Two levers sequentially ≈ 2x that.
