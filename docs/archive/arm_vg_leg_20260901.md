whether it works." (2) = rollout grounding, (3) = search-consistency
targets, from the round-5/6 diagnosis (docs/

## Readout (pre-registered)

Primary: Elo-vs-seed slope from 24-game on-box probes per ~27k-step
pin (both sides MCTS-32, the arm-T frame). Baseline to beat: arm T's
curve (-28, -137, -61, -478, -104, -255, -201, -104, -382 — mean
~-200, violent oscillation). SUCCESS = pins that hold >= 0 or drift
positive; the oscillation shrinking materially is a secondary
positive. Instrument check alongside: profiler dv_consult on a pin
(did the churn drop?) and ground_*/consist_* telemetry columns.

Tripwires: decisive 0.35/20, K-median 10, holdout-stall 60, stall
watchdog, 10-relaunch cap. Escrow: rolling + CSV to HF
tier-b/arm_vg_20260901/ every 30 min.

## Ops

Launcher: scripts/arm_vg_launch.sh (stages: full pytest on box ->
anchor build (500 games from the shipped imitation dataset) ->
fork-guard smoke with VG on -> daemons + supervised training).
Box: 4090, ~5.9GHz cores, vms_enabled=false, --disk 25 (datasets +
pins), ~$0.35-0.45/h. Assets shipped: repo tarball,
replays_dataset_imitation (113MB), replays_dataset (48MB, midgame
mix), seed checkpoint.

Stop-on-abort (user ruling 2026-09-02, after the leg idled ~8h
post-tripwire): every terminal path (tripwire ABORTED_*, relaunch
cap, tests/anchor/smoke failure) runs scripts/box_stop_on_abort.py
— final HF escrow sweep, then the instance is put in the STOPPED
state (GPU billing off, disk kept; ~$0.005/h storage at 25GB).
Provisioning must therefore also write, on the box:
  /workspace/.vast_api_key   (scp ~/.config/vastai/vast_api_key)
  /workspace/.instance_id    (echo <contract id> from `vastai create`)
and `pip install requests vastai` (REST first, CLI fallback). Same
hook lives in scripts/vast_onstart.sh (STOP_ON_ABORT=1 default).
