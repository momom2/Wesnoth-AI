**Reading:** the latest checkpoint is decisively stronger than the 07-13

bought nothing detectable, while the earlier 1.87M→2.30M stretch clearly
did. Consistent with the standing "gold hoarding is LEARNED and
REGRESSING" finding (BACKLOG 2026-07-20), which measured *this same*
07-19 checkpoint hoarding ~100g and recruiting FEWER units.

Caveat: 8 games/matchup is a small sample (the 6-game run's Elo bands were
±400-460), so the ordering is suggestive, not established.
