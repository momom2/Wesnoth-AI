| leg | decision steps | verdict |
|---|---|---|

**Operational consequence:** a box restart resumes from
`tier_a_campaign.pt` = the 3.74M checkpoint, i.e. from the WORST of the
recent lineage. Continuing that run extends a regressing leg. Consider
seeding from the 2.75M or 2.30M checkpoint instead (`-e
HF_SEED_FILE=...` at create time selects which Hub file seeds the
campaign) and/or fixing the suspected cause (draw_tiebreak material
margin / gold hoarding) before spending more GPU hours.

losses) but the sample is small.
